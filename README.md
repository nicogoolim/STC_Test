# TableViewApp

Qt5 десктоп-приложение для просмотра и редактирования табличных данных.

## Возможности

- **Импорт данных** из JSON и CSV файлов
- **Просмотр данных** в табличном виде (QTableView)
- **Редактирование** ячеек таблицы
- **Удаление** строк
- **Экспорт** данных в JSON и CSV форматы
- **Сохранение** данных в SQLite базе

## Сборка

```bash
mkdir build
cd build
cmake ..
cmake --build . --config Debug
```

## Структура

- `src/mainwindow.cpp` - главное окно и UI
- `src/tablemodel.cpp` - модель данных для таблицы
- `src/databaseworker.cpp` - работа с SQLite
- `src/importer.cpp` - импорт JSON/CSV
- `src/importworker.cpp` - асинхронный импорт файлов
- `src/progressdialog.cpp` - диалог прогресса

## Использование

1. Запустите приложение
2. Выберите "Импорт" для загрузки JSON или CSV файла
3. Данные отобразятся в таблице
4. Правый клик по строке - контекстное меню (редактирование, удаление, экспорт)
